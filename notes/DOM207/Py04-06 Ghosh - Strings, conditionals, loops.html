break sl. 20 You can break out of a loop early, whether it's a for or a while, with the break statement. It alters the loop's normal cycle based on criteria that “may not be predictable in advance”. When executed, break terminates the current loop and jumps to the first line after the loop.

Break examplesl. 21–22
print('Only print code if all iterations done')
num = int(input('Enter a number to check for: '))
for i in range(0, 6):
    if i == num:
        break                  # ← just break out of the loop
    print(i, ' ', end='')
print('Done')
Output · sl. 22
Enter a number to check for: 7

Enter a number to check for: 3
0 1 2 Done

The user enters a number that may or may not be in the loop's range. If it is, the loop runs until it reaches that value and then breaks out, terminating early without processing the rest. “Run this and enter the value 7.” With 7 (never reached by range(0, 6)) all six values print. With 3 the loop stops before printing 3. sl. 21–22

Ghosh's note · sl. 22

“The string 'Done' is printed out in both cases as it is the first line after the for loop that is not indented and is thus not part of the for loop.”

The batch in ten lines

  1. / always gives a float in Python 3 (25/5 = 5.0). // gives a whole number (25//6 = 4). Multiplication comes before addition, and parentheses go first.
  2. A string is an ordered sequence of characters in single or double quotes. It can be digits, spaces or symbols.
  3. Indexes run 0 … len−1 from the front and −1 … −len from the back. Name[0] is M, Name[-1] is n, and len("Michael Jackson") is 15.
  4. Slices use [start:stop:step]: Name[0:4] is 'Mich', Name[8:12] is 'Jack', Name[::2] is 'McalJcsn' and Name[0:5:2] is 'Mca'.
  5. + concatenates and * replicates. Strings are immutable, so build a new one instead of changing a character.
  6. \n is a new line, \t a tab and \\ a backslash. r"…" is a raw string that treats \ literally.
  7. Methods return new values: upper() makes capitals, replace(old, new) swaps a substring, and find(sub, start, end) gives the lowest index or −1.
  8. Comparison operators (== != < > <= >=) give True/False. and needs both, or needs either, and not flips.
  9. if / elif / else run the first True branch's indented block. Nested if refines behaviour, and x = a if cond else b assigns in one line. None means no value.
  10. while suits an unknown count and for … in range(start, stop, step) a known one. break leaves the loop and continue skips to the next round; both come from C/C++.

Traps

  • Indexes start at 0; the last is −1. Name[15] is out of range.
  • A slice's stop is not included: [0:4] is 4 characters.
  • Name[0] = "J" is an error (immutable).
  • find returns −1 for no match, not 0 or an error.
  • replace and upper don't change A; they return B.
  • == tests, = assigns.
  • elif branches are checked only if earlier ones failed; only the first True branch runs.
  • input() gives a string, so wrap it: int(input(…)).
  • range(0, 10) ends at 9.
  • break ≠ continue: whole loop vs this iteration.
  • 'Done' prints after break because it's not indented.
  • True/False and None are capitalised.
