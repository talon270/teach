Basics of Python · 44 slides

Python is a free, general-purpose, interpreted and hybrid language (procedural, object-oriented and functional in one), named after Monty Python and the first choice of most data scientists. Use Python 3 only. Code goes through the interpreter, which checks it, compiles it to an intermediate .pyc form and runs that. Write code in a plain editor, never a word processor. Then come the first building blocks: print(), input(), variables with dynamic typing, naming style, the = operator, # comments, and histograms with Matplotlib and Seaborn.

02

Reading Data · 27 slides

Data gets in five ways, from simplest to most practical. input() always returns a string, so cast it. numpy.loadtxt() reads numbers from a text file into an array (and Pylab plots them; data[:,0] takes column 0). open() with read(), readline() and readlines() reads text, and a loop can copy one file to another. CSV is the data scientist's format: read it the hard way with csv.reader or the easy way with pandas.read_csv. Read Excel with xlrd (.xls) or pandas.read_excel (.xlsx).

03

Language Features – 1 · 21 slides

A value's data type is int, float, str or bool, shown by type(). Typecasting converts between them. Watch for lost decimals (int(1.7) is 1), the error from int('A'), and True/False becoming 1/0. Expressions use operands and operators (+ - * / //): / gives a float and // gives a whole number, with multiplication before addition and parentheses first. Variables store values and can be overwritten. A worked example turns album minutes into hours: 142 / 60 ≈ 2.367.

1.4sl. 21–25

How Python runsPython Execution · Execution Model · Steps – 1 · Steps – 2 · Running Python Programs

Python execution sl. 21 Python is not a precompiled language like C and C++. It is an interpreted language: one that needs no separate compilation phase to turn human-readable code into something a computer can execute. The plain-text program goes to another program, the interpreter, which executes it for you.

Execution model sl. 22 In fact Python uses an intermediate model. It converts the plain-text program into an intermediate “pseudo” machine code, and that intermediate format is what gets executed.

Steps – 1 · sl. 23

  1. The program is checked to make sure it is valid Python.
  2. It is checked against all the rules of the language, and that each command and operation is understood by the Python environment.
  3. The plain-text, almost English-like commands are translated into a more concise intermediate format that is easier for a computer to execute.

Steps – 2 · sl. 24

  1. Python can store the intermediate version in a file named after the original but with a .pyc extension instead of .py.
  2. The 'c' means it holds the compiled version of the code.
  3. The interpreter then executes the compiled intermediate version.

Running Python programs sl. 25: four ways.

  1. Interactively, using the Python interpreter
  2. Stored in a file and run with the python command
  3. As a script file that names the Python interpreter to use inside the script
  4. From within a Python IDE, such as COLAB, Spyder, PyCharm, or the simple IDLE

Use of variables sl. 35 “A variable in Python can take various data types!” my_var first holds the string “Jaideep”, then the number 42, then the Boolean True. This is dynamic typing: the type of the data held by a variable can dynamically change as the program runs. Notes: Boolean values can only be True or False. Dynamic typing is not permitted in C, C++ or FORTRAN.

Naming conventions sl. 36 Name your variables in the Python-accepted style.

Acceptable

  • my_name, your_name, user_name, account_name
  • myName, yourName, userName, accountName
  • count, total_num_users, percent_passed, pass_rate
  • where_we_live, house_num
  • is_okay, is_correct, status_flag

Bad: “will work but to be avoided at all costs”

  • A, Aaaaa, aaAAAaa
  • WHEREWELIVE
  • _1ab2cd

Assignment operator = sl. 37 In user_name = input("Enter your name: "), = is the assignment operator. It assigns the value returned by input() to the variable user_name. input() gets input from the user's keyboard. Another example: my_name = "Jaideep".

Ghosh's R comparison

In R the popular form of assignment is <-, though = also works in R. In Python, C, C++, Java etc. the popular form is =. sl. 37

Comments sl. 38 Comments are sections of code the interpreter ignores; they are not executable. A comment starts with # (“this also exists in R”), and everything after it to the end of the line is ignored. Why write them? “To help others and yourself understand what the code is meant to do.”

Histograms sl. 39

  • Used in data visualisation: a graphical representation of the distribution of data.
  • It represents data provided in the form of groups; a graphical representation of numerical data distribution.
  • The X-axis shows the bin ranges; the Y-axis gives frequency.
  • Particularly useful for exploring continuous data, such as numerical measurements.
  • Plotted in Python with the Matplotlib library.

Histograms using Matplotlib sl. 40 First create the bins (intervals) of the ranges. Then spread the whole range of values into a series of bins and count the values that fall in each. Bins are consecutive, non-overlapping intervals of a variable. matplotlib.pyplot.hist() computes and draws a histogram of a variable x.

Pylab sl. 6 A Python module that offers a Matlab-like namespace by importing functions from modules like Numpy and Matplotlib. Numpy provides efficient numerical vector computations based on underlying Fortran and C binary libraries. Matplotlib contains functions to create data visualisations.

What's a namespace? sl. 7 A namespace is “a thing like a catalog used for declarative purposes”. It has a unique name for each and every object in Python, where an object might be a variable or a function. Python maintains a namespace in the form of a Python dictionary.

The syntax data[:,0] sl. 11 data[:, 0] extracts all rows from the 1st column (index 0) of a 2D DF. The comma separates the selection rules for rows and columns: data[rows, columns].

  • : (before the comma) → select every row from start to finish
  • The comma → splits the row selector from the column selector
  • 0 (after the comma) → select the item at index 0, the very first column

The run in ten lines

  1. Python is general-purpose, free, easy, and the language most data scientists say to learn first. It is named after Monty Python. Use Python 3 only (Dec 2008, not backward compatible with Python 2 from Oct 2000).
  2. There are four programming types: procedural (C, Pascal), declarative (SQL), OOP (C++, Java, C#) and functional (Haskell). Python is hybrid and does all of them.
  3. Python is interpreted, not precompiled like C/C++. The interpreter checks the code, compiles it to intermediate “pseudo” machine code (.pyc) and runs that.
  4. Write code in Notepad, Sublime Text or Notepad++, never a word processor. Run it interactively, with the python command, as a script, or in an IDE (COLAB, Spyder, PyCharm, IDLE).
  5. print() is predefined. input() reads from the keyboard and returns a string. = assigns (R: <-) and # comments.
  6. Dynamic typing: one variable can hold a str, then an int, then a bool. C, C++ and FORTRAN don't allow it.
  7. A histogram shows a distribution: bins on x, frequency on y. Use plt.hist(data, bins=30), or sns.histplot(..., kde=True) to add a density curve.
  8. Reading data: input() → loadtxt() (array) → open() + read/readline/readlines → csv.reader → pd.read_csv, then xlrd / pd.read_excel. with closes the file for you.
  9. The types are int, float, str and bool, checked with type(). Casting can lose data (int(1.7) = 1) or fail (int('A')). True/False ↔ 1/0.
  10. / gives a float and // gives a whole number (25//6 = 4). Multiplication before addition, parentheses first. A variable's old value is gone when you reassign it, and age: int = 25 is a type hint.

Interpreted language
No separate compilation phase; an interpreter runs the plain text (via an intermediate form).
.pyc
The stored compiled intermediate version; “c” = compiled.
Hybrid language
Mixes procedural, OO and functional styles in one program.
Object / class / state
An object is an instance of a class (blueprint). The data it holds is its state.
Predefined function
Built into Python; the interpreter knows its definition (print()).
Dynamic typing
A variable's type can change as the program runs.
Namespace
A catalog giving each object a unique name; Python keeps it as a dictionary.
Stringified object
What repr() returns: the object as a printable string.
Typecasting

Ghosh's verdicts

  • Python 3 only.
  • Never a word processor for code.
  • Bad variable names (A, WHEREWELIVE, _1ab2cd) “will work but to be avoided at all costs”.
  • Most data scientists rely on CSV.
  • input() is the simplest read but the most cumbersome.
  • Use meaningful variable names.
  • Variables let you change one input without editing the rest of the code.

Traps

  • input() returns str even when you type 7. type(n) is str until you do int(n).
  • int(1.7) is 1, not 2 (it truncates). int('A') is an error, but int('1') is fine.
  • 25/5 is 5.0 (float), not 5. 25//5 is 5.
  • True/False need capital letters.
  • data[:,0] is the first column (index 0), not the first row.
  • read(10) carries on from where read(4) stopped, and \n counts as a character.
  • readline() returns a string; readlines() returns a list.
  • "w" writes, "a" appends.
  • r"...": the r is not part of the string.
  • .xls uses xlrd; .xlsx uses pandas.read_excel.
  • The OOP languages are C++, Java and C#; the procedural ones are C and Pascal. Don't swap them.
  • .pyc: the “c” means compiled, even though Python is “interpreted”.
